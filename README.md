# ⛩️ Nihongo Quest

Lär dig japanska från noll — hela vägen till ett JLPT N5-prov. Byggt på forskningsbaserade
inlärningsmetoder: mnemonics, spaced repetition, active recall, handskrift och ljud.

**Spela:** https://8bitcat.github.io/nihongo

## Innehåll

- 🌸 **Hiragana** — 14 lektioner med svenska minnesbilder för varje tecken
- ⚡ **Katakana** — 12 lektioner + förväxlingsträning (シ/ツ, ソ/ン)
- 🍜 **Ordförråd** — ~330 JLPT N5-ord i 18 teman med exempelmeningar
- 🖌️ **Kanji** — de 80 klassiska N5-kanji med läsningar och exempelord
- 🧩 **Grammatik** — 10 lektioner: partiklar, ます-form, adjektiv, ko-so-a-do m.m.
- 🎓 **JLPT N5-mockprov** — tre delar som riktiga provet, 0–180 poäng, godkänt vid 80

## Funktioner

- 🔊 Japanskt uttal på allt (talsyntes — bäst i Edge/Chrome)
- 🏮 Daglig SRS-repetition som schemalägger korten precis innan du glömmer dem
- ✍️ Skrivträning på canvas — spåra tecknen, senare rita ur minnet
- ⌨️ Romaji-inmatning med IME-förhandsvisning (både "shi" och "si" funkar)
- 🔥 Streak, XP och japanska ranger från 見習い till 仙人
- 📱 Funkar på mobil och dator, ingen inloggning — allt sparas lokalt

## Kör lokalt

```bash
python -m http.server 8144
# öppna http://localhost:8144
```

Ingen byggprocess — ren HTML/CSS/JS med ES-moduler.
